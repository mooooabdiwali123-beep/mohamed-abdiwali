# Nabad Medical Center Website

Responsive Somali-language hospital/medical center website built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive mobile navigation
- Hero section and service cards
- About, doctors, testimonials and FAQ sections
- Appointment request demo form with client-side validation
- Contact details and clear notes about placeholder content

## Run
Open `index.html` in a browser, or enable GitHub Pages in repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Before using for a real hospital
- Replace the demo name, phone, address, opening hours, doctors, services and placeholder testimonials with verified information.
- Connect the appointment form to a secure backend or booking service. The current form does not transmit or store patient data.
- Do not collect sensitive patient or medical information until privacy, security, access controls and applicable legal requirements are addressed.
- Confirm all services, emergency availability and clinical claims with the facility.
